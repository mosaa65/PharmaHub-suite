# PharmaLove Suite

PharmaLove Suite is a pharmacy management dashboard built with TanStack Start, React, Supabase, and Tailwind CSS.

It covers:

- Inventory and batch tracking
- Purchases and supplier balances
- POS and barcode scanning
- Sales history and returns
- Prescriptions and chronic refill tracking
- Pharmacy settings and reporting

## Tech Stack

- TanStack Start
- React 19
- TypeScript
- Supabase
- Tailwind CSS
- Vite

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Demo Data

If you do not have database credentials for CLI seeding, use:

- `supabase/manual_seed.sql`

Open it in the Supabase SQL Editor and run it manually.

## Notes

- The project uses file-based routing through TanStack Start.
- `src/routes/README.md` contains routing conventions for the app.
